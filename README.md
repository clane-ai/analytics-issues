# Clane Analytics — issues

This is the public issue tracker for [Clane Analytics](https://clane.ai). The product's source is private; this repository holds only bug reports, feature requests and their status.

## Before you post

- **Never attach customer data.** No screenshots of real reports, no row values, no connection details. Redact, or describe the shape of the data instead.
- **Security vulnerabilities are never issues.** See [SECURITY.md](SECURITY.md).
- **Customers with a support agreement** raise customer-specific issues through their private support channel, not here. This tracker is for the product itself.

## How to raise something

- [Report a bug](../../issues/new?template=bug.yml)
- [Request a feature](../../issues/new?template=feature.yml)

## How status works

| Label | Meaning |
|---|---|
| `triage` | Received, not yet assessed |
| `accepted` | Confirmed and on the list |
| `in progress` | Being worked on |
| `fixed in next release` | Fixed on main; ships with the next version |
| `released` | Available; the closing comment names the version |
| `wontfix` | Explained in the closing comment |

Releases and their notes are published with each version; every fixed issue is cited there.
